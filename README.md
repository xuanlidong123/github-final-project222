# Simple Interest Calculator

A simple calculator that calculates simple interest based on principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

The calculator requires:

- Principal amount
- Annual interest rate
- Time period

## Example

Principal = 1000

Rate = 5%

Time = 2 years

Simple Interest = 100

## Usage

Run the Bash script:

./simple-interest.sh

Enter the required values and the calculator will display the simple interest.
